# HR Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyse employee attrition, workforce demographics, job roles, overtime and employee trends.

## 🖥️ Dashboard Preview

![HR Analytics Dashboard](Screenshot%202026-11-12%20113550.png)

## 🎯 Project Objectives

- Analyse employee attrition patterns.
- Understand workforce demographics.
- Identify departments with higher attrition.
- Examine overtime and employee attrition.
- Analyse employee age groups and years of service.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## 📈 Dashboard Features

- Department-wise attrition analysis
- Job role-wise attrition analysis
- Gender distribution
- Age group analysis
- Overtime analysis
- Years-at-company analysis
- Interactive slicers for Department, Gender, Job Role and Overtime

## 💡 Key Business Questions

- Which department has the highest employee attrition?
- Which job roles experience more attrition?
- Which age group contributes most to attrition?
- Does overtime relate to employee attrition?
- How does tenure relate to employee attrition?
